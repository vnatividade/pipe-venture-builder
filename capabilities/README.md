# Capabilities

This directory stores governed capability registry contracts and future registry entries.

Use `architecture/capability-registry-policy.md` before adding or changing capability registry files.

The first registry contract is:

- [Capability schema](capability.schema.json)

Initial registry entries live under:

- [entries](entries/)

Routing validation examples live in:

- [routing examples](routing-examples.md)

This directory does not vendor external repositories, install tools, call MCPs, create adapters, or authorize external actions.

Do not add capability entries without an approved Linear ticket.
