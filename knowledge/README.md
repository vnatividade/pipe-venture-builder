Knowledge artifacts live here.

This area should make decisions, learnings, and operating context durable across agents and product cycles.

- learning log
- [KDR/DAR template](kdr-dar-template.md)

- memory map
- knowledge-base integration notes

Knowledge should be useful for execution, not documentation theater.

Every major phase should either update a useful knowledge surface or explicitly state in the Linear handoff that no reusable knowledge changed.

Use the [venture intelligence memory layer](venture-intelligence-memory-layer.md) as the Markdown-first design for relating ideas, market signals, personas, geographies, evidence, scores, KDR/DAR decisions, and revisit triggers. It does not authorize database implementation, external sync, or sensitive data storage.

Use the [Notion knowledge base policy](notion-knowledge-base-policy.md) when a user or ticket asks whether Notion is part of Pipe's knowledge system. Notion is a governed collaboration, search, and publishing surface; it is not the canonical knowledge base.
