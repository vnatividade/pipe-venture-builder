# Product Context

Use this template when initializing a new venture idea from the base repository.

This file captures product-specific context that future agents need before founder focus, C.O.N.T.R.O.L.E., validation planning, PRD, MVP scope, architecture, or implementation tickets.

Do not store private founder biography, secrets, credentials, sensitive customer data, private customer records, or confidential third-party material here. Keep private/local context outside the repository and link only to approved, non-sensitive source artifacts.
