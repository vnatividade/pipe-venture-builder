# Validation Test Runs

This directory stores reviewed validation run artifacts.

Use it for:

- conversational pipeline mood tests
- validation protocol dry runs
- controlled evidence-capture exercises
- pass/fail records that future agents should be able to inspect

Do not use it for:

- raw customer interviews
- identifiable customer data
- recordings, transcripts, private messages, names, emails, phone numbers, or sensitive material
- customer proof without source-linked validation artifacts
- autonomous outreach, lead sourcing, AI calls, or external communication

Test run artifacts are operating evidence about the Pipe process. They are not customer validation unless the run explicitly includes approved, source-linked customer evidence.
